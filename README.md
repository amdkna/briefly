# Briefly

Briefly یک اپلیکیشن تحت وب برای افرادی است که وقت محدودی دارند اما می‌خواهند از خبرهای مهم و مورد علاقه‌شان عقب نمانند.

این محصول خبرها را از منابع مختلف مانند کانال‌های تلگرام، وب‌سایت‌ها و فیدهای خبری جمع‌آوری می‌کند، محتوای کم‌ارزش و تبلیغات را تا حد ممکن کنار می‌زند، خبرهای مرتبط با علایق کاربر را پیدا می‌کند و آن‌ها را به شکل خلاصه و قابل مرور نمایش می‌دهد.

## Product Goal

تبدیل جریان پراکنده و شلوغ خبرها به یک فید شخصی، خلاصه و باارزش.

> Less noise. More signal.

## Current Stage

ایده در مرحله Product Discovery است. هنوز درباره Stack، معماری و جزئیات پیاده‌سازی تصمیم نهایی گرفته نشده است.
